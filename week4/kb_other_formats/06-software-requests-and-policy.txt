# Software Requests and Policy

## Installing software

Standard users cannot install software directly. This is deliberate. Open the Software Center on Windows or Self Service on macOS and search for the application. If it is listed, click Install and it will be set up within a few minutes without needing administrator rights. The catalogue includes browsers, PDF tools, developer tools, and the standard office suite.

## Requesting software not in the catalogue

1. Check the catalogue twice. Many applications are listed under a different name than you expect.
2. File a ticket with the application name, version, vendor website, and a one-paragraph business justification.
3. The request goes to the security team for a licence and risk review. This takes three to five working days for well-known software and up to three weeks for anything new.
4. If approved, the application is added to the catalogue and you will be notified. If rejected, the ticket will say why and suggest an approved alternative.

## Temporary administrator rights

For installers that genuinely need administrator rights, you can request a 60-minute elevation through the Admin Request tool. Your manager receives an approval prompt. Elevations are logged and audited. Do not use elevation to install software that was rejected in a request; this is a policy violation.

## Browser extensions

Extensions are controlled by an allow list. If an extension is blocked, request it through the same process as software. Ad blockers are allowed. Extensions that read page content on every site, such as grammar checkers, require a security review.

## Licences

Paid software is licensed per user, not per device. If you receive a new laptop, uninstall paid software from the old one before returning it, otherwise the licence stays assigned to the old device and you will be blocked from activating on the new one. If that has already happened, file a ticket and include the old laptop's asset tag.

## Open source

Open source libraries for development are not restricted. Open source desktop applications go through the normal request process, usually on the fast track.
